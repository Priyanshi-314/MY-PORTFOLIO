# Priyanshi Tarsariya — Portfolio

A responsive, accessible and interactive personal portfolio website created for a web development course project.

## What this version includes

- No personal photo — the hero uses a CSS-built coding illustration instead.
- Responsive navigation with mobile menu.
- Dark/light theme toggle saved with localStorage.
- Active navigation section highlighting.
- Scroll reveal animations.
- Accessible skip link.
- Semantic HTML5 structure.
- Descriptive labels and ARIA attributes.
- Responsive CSS for desktop, tablet and mobile.
- Interactive demo contact form.
- Education, skills, projects and learning journey sections.
- GitHub links to `https://github.com/Priyanshi-314`.

## Rubric coverage

### HTML — 5 points
Uses semantic HTML elements including header, nav, main, section, article, form and footer.

### Accessibility — 3 points
Includes:
- skip-to-content link
- accessible navigation
- descriptive button labels
- `aria-expanded`
- `aria-controls`
- `aria-live`
- visible form labels
- decorative visuals marked appropriately

### CSS — 5 points
Separate `css/style.css` provides all visual styling, layout, hover effects, theme variables, responsive media queries and animations.

### JavaScript — 5 points
`js/script.js` provides:
- mobile menu
- dark/light mode
- localStorage theme preference
- active section navigation
- scroll reveal animation
- contact form interaction
- dynamic footer year

### Responsive design — 2 points
The site adapts to desktop, tablet and mobile screen sizes.

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## GitHub Pages

1. Create a GitHub repository.
2. Upload all files/folders from this project.
3. Commit the files.
4. Open Repository → Settings → Pages.
5. Select "Deploy from a branch".
6. Select branch `main` and folder `/ (root)`.
7. Save.
8. Open the published GitHub Pages URL.

## Note

The contact form is a front-end demonstration. It does not send real email because GitHub Pages is a static hosting service.
